## 📌 Proje Hakkında

**CinePick**, kullanıcılara ruh hallerine göre film keşfi sunan modern bir full-stack projedir.

- ☕ **Backend**: Java 25 & Spring Boot (Spring Data JPA, REST Controllers, PostgreSQL).
- ⚛️ **Frontend**: React 19, Vite, Tailwind CSS, Lucide Icons, Axios.

---

## 📂 Proje Yapısı

- `src/`: Spring Boot Java backend kaynak kodları.
- `cinepick/`: React + Vite + Tailwind CSS frontend uygulaması.
